# 环境安装指南

## 安装 Python

### Windows

1. 访问 [python.org](https://www.python.org/downloads/) 下载最新版 Python 3.12
2. 运行安装程序，**务必勾选 "Add Python to PATH"**
3. 打开终端（PowerShell 或 CMD），验证安装：

```powershell
python --version
# 应输出: Python 3.12.x
```

### macOS

```bash
# 使用 Homebrew 安装
brew install python@3.12

# 验证安装
python3 --version
```

### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install python3 python3-pip
```

## 安装 VS Code

推荐使用 Visual Studio Code 作为编辑器：

1. 下载 [VS Code](https://code.visualstudio.com/)
2. 安装 Python 扩展（在扩展市场搜索 "Python"）
3. 推荐扩展：
    - **Python** (Microsoft)
    - **Pylance** (语言服务器)
    - **Black Formatter** (代码格式化)

## 验证环境

创建一个测试文件 `hello.py`：

```python
# hello.py
name = input("请输入你的名字：")
print(f"你好，{name}！欢迎来到 Python 课程。")

# 验证版本
import sys
print(f"Python 版本: {sys.version}")
```

运行：

```bash
python hello.py
```

## 安装 Git

### Windows
下载 [Git for Windows](https://git-scm.com/download/win) 并安装。

### macOS
```bash
brew install git
```

### Linux
```bash
sudo apt install git
```

配置用户名和邮箱：

```bash
git config --global user.name "你的姓名"
git config --global user.email "你的邮箱"
```

## 常见问题

??? question "python 命令找不到？"
    检查是否正确勾选了 "Add Python to PATH"。
    如果没有，需要手动将 Python 安装目录添加到系统环境变量。

??? question "pip 安装包太慢？"
    使用国内镜像源：
    ```bash
    pip install -i https://pypi.tuna.tsinghua.edu.cn/simple 包名
    ```
