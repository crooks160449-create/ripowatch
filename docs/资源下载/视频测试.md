# 视频播放测试

本页面演示如何把清华云盘里的视频直接嵌入课程网站播放。

## 使用方式

在 Markdown 里写：

```text
{{ cloud_video("https://cloud.tsinghua.edu.cn/f/e9a40e45abc34f1386f0/") }}
```

构建时自动解析为下面的播放器：

{{ cloud_video("https://cloud.tsinghua.edu.cn/f/e9a40e45abc34f1386f0/", "屏幕录制演示视频") }}

## 说明

- 视频文件存放在清华云盘，不占用课程网站的 Git 仓库空间
- 播放器支持播放、暂停、拖动进度条、全屏
- 如果云盘外链失效，这里会自动显示为普通链接
