# 面向对象编程

## 类与对象

类是对象的"蓝图"，对象是类的"实例"。

```python
class Student:
    """学生类"""

    # 类属性（所有实例共享）
    school = "Python 学院"

    # 构造方法
    def __init__(self, name: str, age: int, score: float = 0.0):
        # 实例属性
        self.name = name
        self.age = age
        self.__score = score  # 私有属性（双下划线开头）

    # 实例方法
    def introduce(self):
        return f"我叫 {self.name}，今年 {self.age} 岁"

    # getter：安全访问私有属性
    @property
    def score(self):
        return self.__score

    # setter：安全修改私有属性
    @score.setter
    def score(self, value):
        if 0 <= value <= 100:
            self.__score = value
        else:
            raise ValueError("分数必须在 0-100 之间")

    # 特殊方法：定义对象的"字符串表示"
    def __str__(self):
        return f"{self.name} ({self.score} 分)"


# 创建对象
s1 = Student("张三", 20, 88)
s2 = Student("李四", 21, 95)

print(s1.introduce())        # 我叫 张三，今年 20 岁
print(s1.score)              # 88（通过 property 访问）
s1.score = 92                # 通过 setter 修改
print(s1)                    # 张三 (92 分)
```

## 继承

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def say_hello(self):
        return f"你好，我是 {self.name}"


class Teacher(Person):
    """教师类，继承自 Person"""
    def __init__(self, name, age, subject):
        super().__init__(name, age)  # 调用父类构造方法
        self.subject = subject

    # 重写父类方法
    def say_hello(self):
        return f"同学们好，我是教 {self.subject} 的 {self.name} 老师"

    # 新增方法
    def teach(self):
        return f"今天我们来学习 {self.subject}"


t = Teacher("王老师", 35, "Python 程序设计")
print(t.say_hello())  # 同学们好，我是教 Python程序设计 的 王老师 老师
print(t.teach())      # 今天我们来学习 Python程序设计
```

## 多态

不同类可以实现同名方法，表现出不同的行为：

```python
class Dog:
    def speak(self):
        return "汪汪！"

class Cat:
    def speak(self):
        return "喵喵～"

class Duck:
    def speak(self):
        return "嘎嘎嘎"

# 多态：同一接口，不同行为
animals = [Dog(), Cat(), Duck()]
for animal in animals:
    print(animal.speak())
# 汪汪！
# 喵喵～
# 嘎嘎嘎
```

## 类方法 与 静态方法

```python
class Calculator:
    version = "1.0"

    # 类方法：可以访问类属性
    @classmethod
    def get_version(cls):
        return f"Calculator v{cls.version}"

    # 静态方法：不需要访问类或实例
    @staticmethod
    def is_positive(n):
        return n > 0


print(Calculator.get_version())    # Calculator v1.0
print(Calculator.is_positive(42))  # True
```

!!! tip "一句话区分"
    - 类方法用 `@classmethod`，第一个参数是 `cls`（类本身）
    - 静态方法用 `@staticmethod`，不需要 `self` 或 `cls`
    - 普通方法第一个参数是 `self`（实例本身）
