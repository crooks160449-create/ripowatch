# 变量与数据类型

## 变量

Python 中的变量不需要提前声明类型，直接赋值即可：

```python
# 变量赋值
name = "张三"
age = 20
score = 95.5
is_passed = True

print(f"姓名: {name}, 年龄: {age}, 分数: {score}")
```

### 变量命名规则

- 只能包含字母、数字和下划线
- 不能以数字开头
- 区分大小写（`name` 和 `Name` 是不同的变量）
- 不能使用 Python 关键字（如 `if`、`for`、`while`）

```python
# 合法命名
student_name = "张三"
_private = "私有变量"
max_score_2 = 100

# 不合法命名（注释掉）
# 2name = "张三"        # 不能以数字开头
# class = "课程"        # class 是关键字
```

## 基本数据类型

| 类型 | 示例 | 说明 |
|---|---|---|
| `int` | `42` | 整数 |
| `float` | `3.14` | 浮点数 |
| `str` | `"Hello"` | 字符串 |
| `bool` | `True` / `False` | 布尔值 |
| `NoneType` | `None` | 空值 |

### 类型检查与转换

```python
# 检查类型
x = 42
print(type(x))  # <class 'int'>

# 类型转换
y = float(x)    # 42.0
z = str(x)      # "42"
```

## 运算符

```python
# 算术运算符
print(10 + 3)   # 13   加法
print(10 - 3)   # 7    减法
print(10 * 3)   # 30   乘法
print(10 / 3)   # 3.33 除法（浮点）
print(10 // 3)  # 3    整除
print(10 % 3)   # 1    取余
print(10 ** 3)  # 1000 幂运算

# 比较运算符
print(10 > 3)   # True
print(10 == 3)  # False
print(10 != 3)  # True
```

## 字符串操作

```python
# 字符串方法
s = "  Hello, Python!  "
print(s.strip())        # "Hello, Python!"  去除首尾空格
print(s.upper())        # "  HELLO, PYTHON!  "  转大写
print(s.lower())        # "  hello, python!  "  转小写
print(s.replace("Python", "World"))  # 替换

# f-string 格式化
name = "李四"
score = 88
print(f"{name} 的成绩是 {score} 分")  # 李四 的成绩是 88 分
```
