    图片画廊¶

    本页面演示图片画廊功能：把图片放进 docs/assets/gallery/ 文件夹，页面自动显示为可点击放大的相册。

    使用方式¶

    在 Markdown 里写：

    <div class="gallery-grid" id="gallery-grid-0">
  <button class="gallery-item" onclick="openGallery(0, 0)"><img src="../../assets/gallery/示例1.png" alt="图片 1" loading="lazy"></button>
  <button class="gallery-item" onclick="openGallery(0, 1)"><img src="../../assets/gallery/示例2.png" alt="图片 2" loading="lazy"></button>
  <button class="gallery-item" onclick="openGallery(0, 2)"><img src="../../assets/gallery/示例3.png" alt="图片 3" loading="lazy"></button>
</div>

<div class="gallery-lightbox" id="gallery-lightbox-0" hidden>
  <button class="gallery-close" onclick="closeGallery(0)" aria-label="关闭">&#10005;</button>
  <button class="gallery-prev" onclick="galleryNav(0, -1)" aria-label="上一张">&#10094;</button>
  <img class="gallery-stage-img" id="gallery-main-0" src="" alt="">
  <button class="gallery-next" onclick="galleryNav(0, 1)" aria-label="下一张">&#10095;</button>
  <div class="gallery-counter" id="gallery-counter-0">1 / 3</div>
</div>

<style>

}
.gallery-lightbox[hidden] { display: none; }

.gallery-close, .gallery-prev, .gallery-next {

<script>
var galleryImages_0 = [
    "../../assets/gallery/示例1.png",
    "../../assets/gallery/示例2.png",
    "../../assets/gallery/示例3.png"
];
var galleryIndex_0 = 0;

function openGallery(gid, idx) {
  galleryIndex_0 = idx;
  var box = document.getElementById("gallery-lightbox-" + gid);
  box.hidden = false;
  document.body.style.overflow = "hidden";
  galleryUpdate_0();
}

function closeGallery(gid) {
  document.getElementById("gallery-lightbox-" + gid).hidden = true;
  document.body.style.overflow = "";
}

function galleryNav(gid, delta) {
  var arr = window["galleryImages_" + gid];
  galleryIndex_0 = (galleryIndex_0 + delta + arr.length) % arr.length;
  galleryUpdate_0();
}

function galleryUpdate_0() {
  var arr = window["galleryImages_" + gid];
  document.getElementById("gallery-main-" + gid).src = arr[galleryIndex_0];
  document.getElementById("gallery-counter-" + gid).textContent =
    (galleryIndex_0 + 1) + " / " + arr.length;
}

document.addEventListener("keydown", function(e) {
  var box = document.getElementById("gallery-lightbox-0");
  if (box.hidden) return;
  if (e.key === "Escape") closeGallery(0);
  if (e.key === "ArrowLeft") galleryNav(0, -1);
  if (e.key === "ArrowRight") galleryNav(0, 1);
});
</script>

    功能¶

    • 图片自动排成响应式网格
    • 点击任意图片放大查看
    • 左右箭头或键盘方向键切换
    • Esc 键关闭
    • 底部显示当前页码

    添加新图片¶

    把图片文件（png/jpg/gif/webp）直接放进 docs/assets/gallery/ 文件夹，然后执行一键更新。画廊会自动包含新图片，无需修改任何代码。
